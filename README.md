# Portafolio de Ingeniería Informática

¡Hola! Soy Mario, estudiante de Ingeniería Informática interesado
en el desarrollo de software, Linux, redes y Cloud Engineering.

Este repositorio contiene el código fuente de mi portafolio personal,
donde presento mis conocimientos, proyectos y experiencia práctica.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Proyectos

### Portafolio personal

Sitio web personal desarrollado para presentar mis habilidades,
proyectos y avances en mi formación profesional.

### Mini POS

Sistema de punto de venta en desarrollo para administrar
productos y operaciones básicas de una tienda.

Tecnologías previstas:
- Python
- Flask
- PostgreSQL
- HTML y CSS

## Objetivos de aprendizaje

- Mejorar mis habilidades de desarrollo web.
- Aprender administración de sistemas Linux.
- Practicar redes y servicios de infraestructura.
- Desarrollar conocimientos de Cloud Engineering y DevOps.

## Ejecución local

Clona el repositorio:

    git clone git@github.com:carlosmariorueda7-max/portafolio.git

Entra en el directorio:

    cd portafolio

Abre el archivo index.html en tu navegador.
